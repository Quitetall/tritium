# 0012 — Data pipeline: deterministic resumable sharded sampler + `.tqbin`/`.tqidx` (serves: v0.60 / ADR 0008)

## Goal

The ADR 0008 data-pipeline gate (a **CPU** gate, fully reachable): deterministic per-seed shuffle,
no sample duplication or loss across rank shards, resumable mid-epoch. This is the data foundation a
pretraining loop consumes; it's independent of 0011 and the GPU.

**Success:** `cargo test -p tritium-train` (+ `-p tritium-format`) green incl. golden / coverage /
resume / fuzz; `clippy -D warnings` clean; `fmt --check` clean.

## Design

The load-bearing piece is the **sampler**, not the on-disk bytes:

- **`DataSampler`** (`tritium-train/src/data.rs`): given `n_samples N`, `seed`, `n_ranks`, `rank`,
  yields this rank's global sample indices for an epoch. Per-epoch permutation = Fisher–Yates over
  `0..N` driven by `xorshift64(seed ^ epoch_mix)` (the established `gradcheck.rs` PRNG idiom — a
  re-seeded deterministic shuffle, no float, fully reproducible). **Strided rank partition**: rank
  `r` takes permutation positions `r, r+n_ranks, r+2·n_ranks, …` ⇒ disjoint across ranks, union ==
  `0..N` (no dup/loss). **Resumable cursor** = `(seed, epoch, within_epoch_pos)`: restoring it
  continues the identical global order. `drop_last` vs `pad`-to-`n_ranks` multiple is a recorded
  config field (which positions the last short stripe takes).
- **`.tqbin`** (`tritium-format/src/tqbin.rs`): a tokenized corpus shard — LE `magic b"TQBN" |
  version u8 | _reserved u8 u16 | n_tokens u64 | tokens[n_tokens] u32`. Flat concatenated-doc token
  stream (GPT-style packing; the loader cuts fixed `seq_len` windows).
- **`.tqidx`** (`tritium-format/src/tqidx.rs`): the manifest — `magic b"TQIX" | version u8 |
  seq_len u32 | shard_count u32 | per shard: name_len u16 | name | n_tokens u64`. `N =
  Σ_shard floor(n_tokens / seq_len)`. Parsed by a bounds-checked never-panic `Cursor` (mirror
  `salt_bundle.rs`'s discipline).

## Files
- `crates/tritium-format/src/{tqbin.rs, tqidx.rs}` (+ `lib.rs` exports) — the two LE formats + a
  shared never-panic cursor (or reuse the salt_bundle idiom).
- `crates/tritium-train/src/data.rs` (+ `lib.rs` `pub mod data;`) — `DataSampler` + the resume cursor.
- `crates/tritium-train/tests/data_sampler.rs` — golden / coverage / resume property tests (proptest,
  already a dev-dep).
- `crates/tritium-format/tests/tqidx_fuzz.rs` — `.tqidx`/`.tqbin` parser never panics on arbitrary
  bytes (proptest `Vec<u8>`).

## Gates (proptest)
- **golden:** same `(seed, epoch)` ⇒ identical permutation (and same N ⇒ same order).
- **coverage:** for any `(N, n_ranks)`, the union of all ranks' epoch indices == `0..N`, each exactly
  once (no duplication, no loss). With `drop_last`, the dropped tail is exactly `N mod (n_ranks·…)`.
- **resume:** a cursor saved at an arbitrary mid-epoch position + restored yields the exact remaining
  sequence (== the uninterrupted run's tail).
- **fuzz:** `read_tqidx` / `read_tqbin` on arbitrary bytes return `Err`, never panic / OOB / OOM
  (pre-validate lengths before allocating, like `checkpoint.rs::f32_vec`).

## Design notes
- Reuse: `xorshift64` idiom (`gradcheck.rs:50-66`); LE-framing + bounds-checked never-panic `Cursor`
  (`salt_bundle.rs`, `checkpoint.rs`). Determinism: integer-only (no float, no `HashMap` iteration
  order). The cursor is co-located with the optimizer step count so a training checkpoint resumes
  data + weights together (wired in 0013).
- Fisher–Yates needs an `O(N)` index buffer per epoch — fine for the smoke-scale corpora here; a
  streaming/blocked shuffle is a later optimization if N gets huge.

## Done criterion
Golden + coverage + resume + fuzz green; clippy/fmt clean. A deterministic, resumable, dup/loss-free
sharded sampler + the `.tqbin`/`.tqidx` formats — the data substrate the 0013 pretrain loop consumes.
Ships on the `0.5.x` line.

## Outcome — done (tagged `v0.5.2`)
All four gates green: `permutation_is_deterministic`, `coverage_union_is_exact`,
`drop_last_equal_counts_no_dup`, `resume_continues_exactly` (extended to both `drop_last` modes +
the empty-strided-rank path), plus the `tqidx_fuzz` parser-totality proptests; `clippy -D warnings`
+ `fmt --check` clean. `DataSampler` lives in `tritium-train`; `.tqbin`/`.tqidx` + the shared
never-panic `LeCursor` in `tritium-format`.

An adversarial multi-lens review (23 agents, 8 finder angles → verify) surfaced two **major**
defects, both fixed before the tag:
- `drop_last=true` with `n_ranks > n_samples` gave every rank `floor(N/n_ranks)=0` samples — a
  silent zero-data training loop. `new` now asserts the contract (fail-fast), with a `#[should_panic]`
  regression; the coverage proptest excludes the (now-rejected) `n < n_ranks` region so it can't pass
  vacuously.
- `next_index` rebuilt the whole O(N) permutation on every call (O(N²) per epoch on the hot path).
  Now memoized per `(seed, epoch)`, rebuilt only on an epoch roll or `set_cursor` to a different
  epoch/seed — streaming an epoch is O(N).

Plus the verified nits: a dedicated `TqBadName` UTF-8 error (was a misleading `WrongBlockLen`),
determinism/resume doc accuracy (the order also depends on `n_samples`; a resized corpus reshuffles
every index), the biased-modulo draw documented honestly, and a broken cross-crate rustdoc link
dropped. Deferred (out of scope, noted): migrating `salt_bundle`/`gguf`'s private cursors onto the
new shared `LeCursor` — a later cleanup commit, not a v0.60 blocker.
