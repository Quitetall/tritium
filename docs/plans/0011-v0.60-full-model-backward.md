# 0011 — Full-model CPU backward: tape vjps for the transformer ops (serves: v0.60 / ADR 0008)

## Goal

Backprop a **whole** ternary transformer end-to-end on the eager CPU tape — the foundation a
pretraining loop needs, and the wall the v0.50 capstone deferred (plan 0010: full-model PPL recovery
needs full-model backprop). Every new op finite-difference gradient-checked (Gate C, `relative ≤ 2e-3`).

**Success:** `cargo test -p tritium-train` green incl. per-op gradient-checks for the new ops + a
composed tiny-transformer end-to-end gradient-check; `clippy -p tritium-train --all-targets -D warnings`
clean; `fmt --check` clean. **CPU only.**

## What's new vs what composes

The forward (mirrors `tritium-nn`: `runner.rs`, `layers/{transformer_block,mlp}.rs`, `ops/`):
embed → per layer [attn_norm → q/k/v proj → RoPE → GQA attention → o_proj → +residual → ffn_norm →
gate/up proj → relu²⊙ → ffn_sub_norm → down proj → +residual] → output_norm → tied LM head → xent.

- **Compose from existing tape ops** (no new code): gated-MLP = `matmul`(gate)→`relu2`→`matmul`(up)→
  `mul`→[ffn_sub_norm]→`matmul`(down); residual = `add`; the projections = `matmul`/`dense`; the loss
  = `softmax_xent` (have). The LM head = `dense` (tied embedding as the weight).
- **New tape ops** (forward + vjp, each gradient-checked):
  1. **`rmsnorm`** (`ops/norm.rs`) — `y[r,i] = x[r,i]·inv_r·w[i]`, `inv_r = 1/√(mean_i(x[r,i]²)+eps)`.
     Used by attn_norm/ffn_norm/sub_norms/output_norm. vjp:
     `gw[i] = Σ_r g[r,i]·x[r,i]·inv_r`; `gx[r,k] = inv_r·g[r,k]·w[k] − inv_r³·x[r,k]·(Σ_i g[r,i]·w[i]·x[r,i])/n`.
  2. **`rope`** (`ops/rope.rs`) — NeoX half-rotation by per-position angles (mirror `ops/rope.rs`).
     Rotation is orthogonal ⇒ vjp is the transpose (rotate the cotangent by −θ). Positions are data.
  3. **`softmax`** (`ops/softmax.rs`) — row-wise stable softmax `p = softmax(x_row)`. vjp:
     `gx = p ⊙ (g − (Σ p·g))` per row. (Distinct from the fused `softmax_xent` already in `loss.rs`.)
- **Attention** then composes: `scores = dense(Q, K)·(1/√d)` → causal-mask (additive −inf upper
  triangle; a small `causal_mask` tape op or fold into the score build) → `softmax` (per query row) →
  `dense(P, V)`. GQA = each KV head feeds `n_head/n_head_kv` query heads (index mapping, no new math).
  Built as a per-(head) composition in the tiny-transformer test; a `attention` helper may wrap it.

## Design notes
- **Reuse** `gradcheck::check_op` (central FD, Gate-C `Tolerance{relative:2e-3}`), the xorshift64
  `seeded` idiom, and the existing op style (hand-written `forward` + `vjp`, `#[allow(needless_range_loop)]`).
- **Fixtures off kinks:** softmax is smooth; relu² has a kink at 0 (keep fixtures off it); rmsnorm
  needs `mean_sq+eps > 0` (nonzero rows). Causal mask uses `−inf` in the forward but the masked
  positions get exact-0 softmax prob ⇒ 0 gradient (fine); keep FD perturbations off masked entries.
- **No new model-forward in tritium-nn** — the tape composition is self-contained; faithfulness to the
  deployed forward is a 0013 concern (device backward == CPU vjp), not here.
