# 0006 — tritium-train CPU op set + reverse-mode tape + composed gradient (TDD)  (serves: v0.50 / ADR 0007, Gate C)

## Goal

Complete the CPU half of the QAT autograd: the remaining trainable ops (bias, squared-ReLU,
MSE + softmax-cross-entropy, element-wise add/mul), each a hand-written forward + `vjp`
gradient-checked against the central finite difference; and a **reverse-mode tape** that
composes them — plus the 0005 STE + ternary-matmul ops — into a differentiable QAT toy layer
whose end-to-end gradient is validated element-by-element against finite differences. This
closes ADR 0007 **Gate C on CPU**: every trainable op *and* the autograd graph reproduce the
analytic gradient within `relative ≤ 2e-3`. **CPU-only**, no new external deps.

**Success:** `cargo test -p tritium-train` green (13 tests); `cargo clippy -p tritium-train
--all-targets -- -D warnings` clean; `cargo fmt -p tritium-train --check` clean.

## Design notes (load-bearing; carry forward to 0007/0008/0010)

1. **STE surrogate in the differentiable path (inherited from 0005).** Any FD-checked forward
   that crosses the quantizer must thread `ste::quantize_surrogate` (`clamp(Wf/s_q,-1,1)`, no
   `round`), never `quantize_forward`. The tape's quantizer slot uses the surrogate; `round` is
   a forward-only QAT value detail (0010). The STE `vjp` is the surrogate's exact gradient.

2. **The matmul forward is a real float contraction, not the inference kernel.** `matmul::forward`
   computes `Y[m,n] = s[n]·Σ_k A[m,k]·W[n,k]` over real `f32` weights. It must NOT route through
   `tritium_core::reference_mpgemm`: that kernel's add/sub/skip form sign-collapses weights
   (`Trit::from_sign(x as i8)`), making the **weight path piecewise-constant** — which silently
   zeroes the finite-difference gradient w.r.t. `Wf` (caught as a false-green in review; see
   *Review*). The float contraction is differentiable in `W` and equals `reference_mpgemm`
   bit-for-bit at ternary `W` (anchored by `real_forward_matches_reference_at_ternary`, the
   `1e-4` convention the core's own add/sub/skip-vs-float prop test uses). The QAT value path
   (0010) may still call `reference_mpgemm` for the ternary inference forward; the autograd op
   records the real-contraction value + the `vjp`.

3. **Tape contract.** `ValueId` is a plain `usize` index into the tape's arena; ids must come
   from the *same* tape and the dims passed to op methods must match their buffers (violations
   panic via indexing). `backward(loss)` seeds the scalar loss with cotangent 1, walks nodes in
   reverse (forward-record order is a valid topo order because every output id is fresh and
   larger than its inputs), and **accumulates** (`+=`) input grads so fan-out sums correctly.

## Op backward formulas (the spine — port these to CUDA in 0007)

| op | forward | vjp |
|----|---------|-----|
| `bias` | `Y[m,n]=X[m,n]+b[n]` | `gX=gY`, `gb[n]=Σ_m gY[m,n]` |
| `relu2` | `Y=max(x,0)²` | `gX=gY·2·max(x,0)` (C¹ at 0) |
| `mse` | `L=mean((pred−t)²)`, N=all elems | `gPred=gOut·(2/N)(pred−t)` |
| `softmax_xent` | `L=mean_r(−Σ_c t·ln softmax(z))` | `gZ[r,c]=gOut/rows·(p[r,c]·Σ_c t[r,·] − t[r,c])` |
| `add` | `Y=A+B` | `gA=gY`, `gB=gY` |
| `mul` | `Y=A⊙B` | `gA=gY⊙B`, `gB=gY⊙A` |
| `matmul` (0005, corrected) | `Y[m,n]=s[n]·Σ_k A·W` | `gA=Σ_n gY·s·W`, `gs[n]=Σ_m gY·P` (P unscaled), `gW=s·Σ_m gY·A` |
| `ste` (0005) | `round(clamp(Wf/s_q))` / surrogate `clamp(Wf/s_q)` | `gWf=gOut·(1/s_q)·1[|Wf/s_q|<1]`, `g_sq=0` |

`target` (mse/xent) and `s_q` (ste quantizer scale) are constants of the forward (stop-gradient).
`softmax_row` subtracts the row max before exp (overflow-safe) and clamps `p` at `f32::MIN_POSITIVE`
before `ln`.

## Review  *(planner)* — outcome recorded

Three independent adversarial lenses (gradient-math, numerical-soundness, rust/API).

- **gradient-math: PASS** — all vjps re-derived + FD-checked; tape reverse-order/seed/accumulate
  verified, incl. cross-op and same-id fan-out. (Did *not* catch the matmul false-green — the
  forward looked surrogate-threaded at the call site.)
- **numerical-soundness: NEEDS-CHANGES → fixed.** Caught a **false-green**: the composed test's
  forward routed through the sign-collapsing matmul, so FD w.r.t. `Wf` was exactly 0 while the
  tape backprop'd the continuous surrogate (`|g_wf[0]|≈0.104`); only the lucky scalar cotangent
  `r=−0.008` scaled the mismatch under the bar (≈2% of seeds). **Fix:** real-contraction matmul
  forward (note 2) + the composed test now compares tape grads *directly* to per-element FD (no
  cotangent). A **negative control** (reintroduce the truncation) fails exactly as predicted
  (`analytic 0.1038 vs numeric 0`), proving the test now has teeth. Confirmed-clean items:
  relu² C¹ kink benign, softmax max-subtraction stable + clamp never hit, truncation comfortable.
- **rust/API: PASS-WITH-NITS → addressed.** Closures all `'static`; `Default`/manual-`Debug`
  correct; no leak/aliasing. Added `# Panics` to `mse_vjp`/`softmax_xent_vjp` (read `grad_out[0]`)
  and a `ValueId`/dims contract note on `Tape`. Self-contained ops justified (depending on
  `tritium-nn::softmax_rows` would invert the dep graph; it is in-place + fallible, a different
  contract).

**Deferred to later plans (design nits, not bugs):** newtype `ValueId` for cross-tape safety and
a leaf-only grad accessor / leaf enumeration — useful before **0008** wires the optimizer over
leaves (today a caller hand-indexes the full-arena `backward` result, as `composed_grads` does).
