# Research records

Tritium keeps its full preregistered research archive and living work plan in a
maintainer-only repository. Public users do not need access to that archive to
use the released APIs or reproduce documented results.

This repository publishes decision records after their decisions have shipped;
the [public ADR index](https://github.com/Quitetall/tritium/tree/main/docs/adr)
and [research-record policy](https://github.com/Quitetall/tritium/blob/main/docs/RESEARCH.md)
describe that boundary. Current release gates are maintained in the
[release-candidate guide](https://github.com/Quitetall/tritium/blob/main/docs/release-candidate.md).

If you need a specific decision or work order to reproduce a supported behavior,
request it through the [public issue tracker](https://github.com/Quitetall/tritium/issues).
Do not treat an inaccessible internal plan as a public API or release claim.
