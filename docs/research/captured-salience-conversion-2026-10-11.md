# Mandatory captured conversion

Implements the captured-conversion amendment in research ADR0064. This is a
distinct experimental structural profile, not captured arithmetic truth,
fit optimality, real-model quality/performance, SOTA or public release clearance.

The carrier is canonical CBOR
`["tritium.captured-salience-conversion.v1", CapturedSalienceConversionManifest]`.
It includes the unchanged complete A->B->C lineage plus a mandatory complete
registered B capture run/span/root. Existing ordinary and joined readers reject
it; old `tritium.salience-conversion.v1` bytes and semantics remain unchanged.
Both profiles reuse one private canonical/profile codec, not separate encodings.

`Engine::run_captured_salience` takes actual admitted B, a complete standalone
capture log and existing calibrated plan/provider/sink/recorder/limits. Stage,
source, transform, actual tokenizer assets and captured matrix interpretations
must agree. Every calibrated action must use the exact recorded cache binding;
plain uncalibrated fits reject. Explicit KeepDense remains allowed, including
the tied table until complete gather/tied-consumer estimation is admitted.
Captured but unused consumers are not claims of calibrated/fitted weights.

The common SalienceProductionContext checks this join before fitting and again
against actual completed fit observations. It selects the mandatory carrier
before the one common package write, then performs captured joined admission
before the existing sink publishes. No legacy C publication followed by repack,
fake Identity fit/receipt, second fitter or dense B clone is introduced.

`JoinedSalienceModel::open_captured` requires actual admitted B, the exact complete
capture log and actual complete conversion log. Required capture root, every
calibrated cache, source/transform/conversion roots and all physical semantic
payloads must agree. The ordinary joined opener still rejects this profile.
After admission the view retains only C metadata/capture reference, not B or
raw capture text/gradients. The existing joined runtime selector is reused.

Structural binding cannot independently establish complete graph execution or
numerical cache/transform truth. Actual cold NN graph/tokenizer/backward replay
and actual original-A transform replay remain separate verifier levels. This
does not add NN dependencies to quantize or copy graph mappings there. Existing
package/manifest bounds are not complete log/parser/tape/RSS admission.

Actual record->cold replay->fit->package->cold captured open->CPU/reference
prefill/cached decode tests exercise F32/F16/Bf16 stored sources, foreign roots,
rehash substitutions, missing capture consumers, plain-fit/cache swaps and
pre-publication rejection. No hardware or real-model qualification follows.
Original-A capture, gather/hybrid/MTP, both campaigns/surface migrations and all
unchanged full ADR0033 fitting/refinement/GPU/memory/format, hardware/browser,
quality/runtime/bytes/reproduction, serving/security/packaging/zoo/docs/community/
signing and explicit human activation obligations remain required.
